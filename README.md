# Mehara

Personal workspace of Mehara Rothila Ranawaka ([@mehara-rothila](https://github.com/mehara-rothila)) for the JARVIS IS4990 project: experiments, notebooks, test scripts and learning.

**The real project lives in the main repo, [jarvis-uom/is4990-project](https://github.com/jarvis-uom/is4990-project).** Tasks, weekly updates, decisions and the final code all go there.

## Rules

- Try anything here. It doesn't have to be tidy.
- When something works, move it into the main repo with a pull request. Do it every week, not at the end.
- Don't create tasks here. Tasks and weekly progress live in the main repo, so the whole team sees them.
- No large data (satellite images, videos, datasets, model weights) and no passwords or API keys. The `.gitignore` blocks the common file types. The full team rules are in the main repo's [CONTRIBUTING.md](https://github.com/jarvis-uom/is4990-project/blob/main/CONTRIBUTING.md).
